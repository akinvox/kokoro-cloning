02 / Expressive reference · stress test

Where v1 has more work to do

A slow, soft reference with deliberate pauses and stretched words. Listen for differences in pace, breathiness, emphasis and voice identity. The same-text clone makes delivery differences easier to hear; the new-text clone shows how the reference carries onto other words. Highly expressive delivery is a known v1 limitation.

About this project

I’m building this for my audiobook site, akinvox.com . The goal is voice cloning without sacrificing quality or speed.

V1 has had 100k cloning updates on pretrained Kokoro. I believe more training could improve it substantially, and work on v2 is ongoing.

The site is still under construction. I’d appreciate you giving it a go.
